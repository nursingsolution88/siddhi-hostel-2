# Siddhi Hostel Professional Management System

## Features
- Professional responsive dashboard
- Hostel hero image and premium blue template
- 18 rooms × 3 beds
- Student admission
- Room/bed status
- Joining-date based due calculation
- Due and overdue list
- Email reminder
- Payment done
- Receipt ID and receipt email
- Daily automation and monthly report
- Student search

## Installation
1. Google Sheet खोलें.
2. Extensions → Apps Script.
3. `Code.gs` का पूरा code paste करें.
4. `+` → HTML file → नाम `index` रखें.
5. `index.html` का code paste करें.
6. `Code.gs` में OWNER_EMAIL में अपनी email लिखें.
7. `setup()` function एक बार Run करें और permissions Allow करें.
8. Deploy → New deployment → Web app.
9. Execute as: Me.
10. Who has access: Anyone.
11. Deploy करके Web App URL खोलें.
